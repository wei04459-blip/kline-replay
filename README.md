# K线回放

在本机浏览器里回放 Binance 公开历史现货行情，练习观察和模拟交易。无需登录、账号或云服务。

GitHub 项目：[`wei04459-blip/kline-replay`](https://github.com/wei04459-blip/kline-replay)。

## 启动

Clone 项目后，在项目根目录运行本项目自带服务即可完整练习：

```sh
git clone https://github.com/wei04459-blip/kline-replay.git
cd kline-replay
/usr/bin/python3 macos/Contents/Resources/serve.py --bind 127.0.0.1 --port 8765 --directory "$PWD/dist"
```

再打开 <http://127.0.0.1:8765>。终端服务在前台运行，按 `Control-C` 停止。也可以在 Finder 中双击项目根目录的 `启动练习场.command` 启动，双击 `停止练习场.command` 停止。两个脚本只管理本启动器记录且命令行匹配的服务；不会结束其他占用端口的进程。

服务只绑定本机回环地址。首次访问某个UTC日会从 [Binance 官方公开日归档](https://github.com/binance/binance-public-data/) 下载该资产的1分钟K线及 `.CHECKSUM`，验证SHA256后放入 `~/Library/Caches/com.yuwan.local.kline-replay/minute-v1/`。以后相同日期可从本地缓存读取；未缓存日期首次使用需要网络。官方日文件通常次日发布，历史练习范围为2022至2025 UTC。下载失败或校验错误会显示错误并保留回放位置，不补造价格。分钟接口每次只返回一个UTC日（最多1,440根），前端逐根消费；浏览器端最多保留最近读取的3个日文件，服务端缓存每个资产最多180日。

纯静态服务器（例如 `python3 -m http.server`）只能预览内置15分钟历史图表，无法完整推进练习，也没有真实1分钟接口；页面不会在接口不可用时悄悄改回15分钟模拟路径。

如果已有 `K线回放.app`，macOS 用户可双击它启动本地网页和分钟数据接口。应用只监听 `127.0.0.1:8765`，会按专用响应标记识别并复用同应用服务；若该端口由其他服务占用，会提示并退出，不会结束或覆盖那个进程。应用包自带静态资源和服务代码，不依赖项目源目录。停止应用服务：在 Finder 中对 `.app` 右键选择“显示包内容”，打开 `Contents/Resources/停止服务.command`。应用包的使用说明副本位于 `Contents/Resources/README.md`。

## macOS 应用包

在 macOS 和 Python 3 环境中运行打包脚本：

```sh
/usr/bin/python3 scripts/打包桌面应用.py
```

脚本会生成 `build/K线回放.app`，从 `macos/Contents/` 复制启动模板及本地行情服务，将本项目的正式 `dist/` 页面、分钟数据模块、数据和图表许可证按白名单收进应用包，并使用 `assets/K线回放.iconset/` 生成 ICNS 图标。构建需要 macOS 自带的 `iconutil`；不会启动应用或浏览器，也不会覆盖桌面已有应用。生成后可手动复制到“应用程序”或桌面。

## 行情与练习

- 内置 BTC/USDT、ETH/USDT 的 Binance Vision 现货 15 分钟数据，UTC 范围为 2022-01-01 至 2025-12-31；时间戳使用 Unix 秒。
- 真分钟形成路径使用 Binance Vision 现货1分钟日归档（OHLCV），每分钟仍是一根分钟K线，不是逐笔成交或tick；分钟数据只由本地服务按需读取和缓存。单根15分钟K线由已经到达的分钟K线逐步聚合，未到达的分钟不会参与显示或撮合。Spot归档2025-01-01起使用微秒时间戳，服务验证后统一转换为Unix秒。
- 数据文件在 `dist/data/`，每个 JSON 均附公开月度归档 URL、官方 `.CHECKSUM` URL 和 SHA256。下载脚本会校验校验和、OHLC、顺序和时间间隔。
- 官方15分钟归档在 2023-03-24 12:45 至 13:45 UTC 缺少 5 根K线（前后相邻15分钟记录为 12:30 和 14:00 UTC）。对应1分钟日归档在 12:40 至 13:59 UTC 缺少80根，亦覆盖前一根12:30的最后5分钟。数据如实保留空档，不插值或补造价格；分钟路径遇到缺口时跳到下一根真实分钟K线。

可以练习 15 分钟、30 分钟、45 分钟、1 小时、4 小时、日线和周线。较大周期按当前练习路径聚合；回放只显示已揭示的行情，未来 K 线不会提前出现。所有时间按 UTC 显示。1分钟数据是每分钟 OHLCV 聚合，不是逐笔成交或tick；分钟内部的成交先后顺序仍然未知。

## 下单与回放

1. 先选市价或限价，再选买入/做多或卖出/做空；当前方向按钮会高亮并显示“✓已选做多”或“✓已选做空”。限价单在图上选择入场价；市价单按当前已揭示的收盘价作为入场参考。
2. 用杠杆滑条选择 1–100 倍（默认 1×），再用 0–100% 保证金比例滑条确定本次保证金占账户预算比例，精度为 0.1%；也可点 10%、25%、50%、95% 预设按钮。名义仓位按杠杆换算，100% 档会为保证金与开仓手续费预留预算，0% 时不能下单。面板同时显示名义仓位、保证金、开仓手续费和预估强平价；已有挂单或持仓期间不能更改杠杆。
3. 图上先显示入场线；止损和止盈的“＋”标记贴在入场价旁。拖出某个标记才设置对应价位，未拖出的止损或止盈保持未设置。已设置的价位旁有“×”，点击可取消；取消后标记回到入场价旁，可再次拖出。市价单的入场价按确认时已揭示的收盘价锁定。确认后，市价单立即按当前收盘价及滑点模拟成交；限价如果已可成交，会立即按指定价或更优价模拟成交，否则转为挂单，从后续真实1分钟K线开始检查触价，成交价不会比限价更差。拖动限价改单后也按同一规则处理。
4. 限价挂单和持仓期间，都可以在图上添加、取消或拖动修改止损/止盈；只有未成交的限价挂单可以修改入场价。图上线位编辑先作为待确认预览，右侧点击“确认修改”后才生效；点击“取消”会恢复实际价位。未确认的修改只保留在当前页面，刷新后丢弃。尚未成交的限价单也可撤销。底部区域查看当前持仓、挂单、本轮成交历史和往期练习。
5. 每轮只管理一个当前挂单或一笔持仓。切换 BTC/ETH 会开启新一轮：当前持仓按已揭示价格平仓，未成交挂单取消，练习记录归档。

提交订单前会打开一个可拖动的理由浮窗，回放会暂停；浮窗打开时，图表仍可缩放和拖动，方便查看行情。理由必填，去除首尾空白后仍需有内容，最多 2,000 字符。确认后才提交订单；取消浮窗不会下单。提交成功或取消后会恢复打开前的播放状态。理由会随挂单、持仓和成交历史保存，并包含在 JSON 导出中，便于复盘。

可用空格播放/暂停；按 `N` 或点“下一分钟”推进一根真实分钟K线，按 `→` 或点“下一根”快进至当前所选周期的边界。默认1×约每1.5秒推进1分钟。限价成交和止盈止损触发后，若回放原本正在播放就继续；理由窗是唯一会临时暂停回放的业务操作，取消或成功下单后恢复原来的播放状态。网络错误会保留进度，可重试。MA10 与 MA20 可独立显隐，均按当前已回放数据计算；日期遮挡只隐藏界面文字，完整日期仍在本地行情 JSON 中。

## 模拟成交的边界

模拟初始余额为 10,000 USDT，支持 1–100 倍逐仓模拟，默认 1×。强平价按固定 0.5% 维持保证金率、回放中的真实现货分钟价估算，属于预估触发价，不是交易所标记价格或真实强平价；不含资金费和分档维持保证金。强平属于平仓成交，回放按原有播放状态继续。单边手续费 0.04%，成交时计入 0.02% 不利滑点。极端跳空时可能产生逐仓结算补差，相关数值会写入成交记录。已设置的止盈止损和限价单按真实1分钟K线检查；未设置的止损或止盈不会自动平仓。分钟K线内部的先后路径无法从 OHLC 数据获知，所以同一分钟触及止损和止盈时按止损计；限价入场所在分钟会检查止损与强平，止盈从下一分钟开始检查。若分钟开盘已跳空越过强平价，优先按强平处理；同一分钟内止损和强平价都触及时，按先经过的保护阈值处理（多仓取价格较高者，空仓取价格较低者）。跳空触发止盈或止损时按开盘价成交。每分钟K线仍是OHLC聚合，并不能还原逐笔成交顺序。

这里的做多/做空、订单和盈亏都是练习用模拟结果，不是 TradingView 官方 Paper Trading，也不是交易所撮合；不含盘口深度、资金费或分档维持保证金；强平价仅为基于现货回放价格的逐仓模拟估值，不等于交易所标记价格或真实强平，不代表真实成交或投资结果。可以参考 [TradingView Paper Trading 操作说明](https://www.tradingview.com/support/solutions/43000516466-paper-trading-main-functionality/) 了解常见纸上交易操作，但本练习场是独立的本地工具。

## 隐私与记录

练习轮次、订单理由、成交和笔记保存在当前浏览器对应站点的 `localStorage`，不会由此页面上传到云端。清理浏览器站点数据会删除记录；可使用页面导出功能备份。不同浏览器及浏览器配置文件的存储相互隔离，Codex 预览与默认浏览器也不会自动互通；在一个环境里的练习记录不一定出现在另一个环境。盲回放只在界面隐藏日期，完整行情仍在本地数据文件中。

## 数据更新

仓库内附完整15分钟行情文件，纯静态模式可离线使用。分钟日档按需下载到用户缓存目录，不放入仓库、桌面应用包或练习导出；只缓存已请求日期，因此尚未缓存的日期在离线时不可用。缓存会限制为每个资产最近180个UTC日，删除缓存不会影响已保存的练习记录。需要重新下载或更新内置15分钟行情时，在项目根目录运行 `/usr/bin/python3 scripts/下载历史行情.py`；月度 ZIP 与 `.CHECKSUM` 会暂存在被 Git 忽略的 `.cache/` 中以便恢复。来源失败或数据不完整时脚本会报告错误，不会以不完整行情替换已有 JSON。图表库保留其上游 LICENSE 与 NOTICE；本项目未添加自有开源许可证。
