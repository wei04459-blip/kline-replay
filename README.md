# K线回放

在本机浏览器里回放 Binance 公开历史现货行情，练习观察和模拟交易。无需登录、账号或云服务。

GitHub 项目：[`wei04459-blip/kline-replay`](https://github.com/wei04459-blip/kline-replay)。

## 启动

Clone 项目后可直接使用 Python 3 启动，不用先生成 macOS 应用包：

```sh
git clone https://github.com/wei04459-blip/kline-replay.git
cd kline-replay
/usr/bin/python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

再打开 <http://127.0.0.1:8765>。终端服务在前台运行，按 `Control-C` 停止。

如果已有 `K线回放.app`，macOS 用户可双击它启动本地网页。应用只监听 `127.0.0.1:8765`，会按专用响应标记识别并复用同应用服务；若该端口由其他服务占用，会提示并退出，不会结束或覆盖那个进程。应用包自带页面和数据，不依赖项目源目录。停止应用服务：在 Finder 中对 `.app` 右键选择“显示包内容”，打开 `Contents/Resources/停止服务.command`。应用包的使用说明副本位于 `Contents/Resources/README.md`。

## macOS 应用包

在 macOS 和 Python 3 环境中运行打包脚本：

```sh
/usr/bin/python3 scripts/打包桌面应用.py
```

脚本会生成 `build/K线回放.app`，从 `macos/Contents/` 复制启动模板，将本项目的正式 `dist/` 页面、数据和图表许可证按白名单收进应用包，并使用 `assets/K线回放.iconset/` 生成 ICNS 图标。构建需要 macOS 自带的 `iconutil`；不会启动应用或浏览器，也不会覆盖桌面已有应用。生成后可手动复制到“应用程序”或桌面。

## 测试

引擎测试使用 Node.js 20 或更新版本：

```sh
node --test tests/engine.test.mjs
```

## 行情与练习

- 内置 BTC/USDT、ETH/USDT 的 Binance Vision 现货 15 分钟数据，UTC 范围为 2022-01-01 至 2025-12-31；时间戳使用 Unix 秒。
- 数据文件在 `dist/data/`，每个 JSON 均附公开月度归档 URL、官方 `.CHECKSUM` URL 和 SHA256。下载脚本会校验校验和、OHLC、顺序和时间间隔。
- 官方归档在 2023-03-24 12:45 至 13:45 UTC 缺少 5 根 15 分钟 K 线（前后相邻记录为 12:30 和 14:00 UTC）。数据如实保留空档，不插值或补造价格；各文件的 `gaps` 与 `continuous` 字段记录此情况。

可以练习 15 分钟、30 分钟、45 分钟、1 小时、4 小时、日线和周线。较大周期由 15 分钟 K 线聚合；回放只显示已揭示的行情，未来 K 线不会提前出现。所有时间按 UTC 显示。

## 下单与回放

1. 先选市价或限价，再选买入/做多或卖出/做空；当前方向按钮会高亮并显示“✓已选做多”或“✓已选做空”。限价单在图上选择入场价；市价单按当前已揭示的收盘价作为入场参考。
2. 用 0–100% 仓位滑条设定下单比例，精度为 0.1%；也可点 10%、25%、50%、95% 预设按钮。滑条为 0% 时不能下单；100% 档会预留手续费。
3. 图上先显示入场线；止损和止盈的“＋”标记贴在入场价旁。拖出某个标记才设置对应价位，未拖出的止损或止盈保持未设置。已设置的价位旁有“×”，点击可取消；取消后标记回到入场价旁，可再次拖出。市价单的入场价按确认时已揭示的收盘价锁定。确认后，市价单立即按当前收盘价及滑点模拟成交；限价如果已可成交，会立即按指定价或更优价模拟成交，否则转为挂单，从之后真实的 15 分钟 K 线开始检查触价，成交价不会比限价更差。拖动限价改单后也按同一规则处理。
4. 限价挂单和持仓期间，都可以添加或取消止损、止盈。当前未设置的价位不会触发对应的自动退出；仍可手动市价平仓。尚未成交的限价单也可在图上拖动改单或撤销。底部区域查看当前持仓、挂单、本轮成交历史和往期练习。
5. 每轮只管理一个当前挂单或一笔持仓。切换 BTC/ETH 会开启新一轮：当前持仓按已揭示价格平仓，未成交挂单取消，练习记录归档。

提交订单前会打开一个可拖动的理由浮窗，回放会暂停；浮窗打开时，图表仍可缩放和拖动，方便查看行情。理由必填，去除首尾空白后仍需有内容，最多 2,000 字符。确认后才提交订单；取消浮窗不会下单。理由会随挂单、持仓和成交历史保存，并包含在 JSON 导出中，便于复盘。

可用空格播放/暂停，点“下一根”或按方向键逐根回放；自动止盈止损后会暂停。MA10 与 MA20 可独立显隐，均按当前已回放数据计算；日期遮挡只隐藏界面文字，完整日期仍在本地行情 JSON 中。

## 模拟成交的边界

模拟初始余额为 10,000 USDT，按 1 倍名义仓位计算。单边手续费 0.04%，成交时计入 0.02% 不利滑点。已设置的止盈止损和限价单按 15 分钟真实 K 线检查；未设置的止损或止盈不会自动平仓。每根 K 线内部的先后路径无法从 OHLC 数据获知，所以规则采用保守处理：限价入场与止损在同一根 K 线触发时按止损计；入场同根只检查已设置的止损，已设置的止盈从下一根开始检查；旧持仓若新 K 线开盘跳空越过已设置的止盈或止损，优先按开盘价触发。

这里的做多/做空、订单和盈亏都是练习用模拟结果，不是 TradingView 官方 Paper Trading，也不是交易所撮合；不含盘口深度、资金费或杠杆强平，不代表真实成交或投资结果。可以参考 [TradingView Paper Trading 操作说明](https://www.tradingview.com/support/solutions/43000516466-paper-trading-main-functionality/) 了解常见纸上交易操作，但本练习场是独立的本地工具。

## 隐私与记录

练习轮次、订单理由、成交和笔记保存在当前浏览器对应站点的 `localStorage`，不会由此页面上传到云端。清理浏览器站点数据会删除记录；可使用页面导出功能备份。不同浏览器及浏览器配置文件的存储相互隔离，Codex 预览与默认浏览器也不会自动互通；在一个环境里的练习记录不一定出现在另一个环境。盲回放只在界面隐藏日期，完整行情仍在本地数据文件中。

## 数据更新

仓库内附完整行情文件，首次 Clone 后即可离线练习。需要重新下载或更新行情时，在项目根目录运行 `/usr/bin/python3 scripts/下载历史行情.py`；月度 ZIP 与 `.CHECKSUM` 会暂存在被 Git 忽略的 `.cache/` 中以便恢复。来源失败或数据不完整时脚本会报告错误，不会以不完整行情替换已有 JSON。图表库保留其上游 LICENSE 与 NOTICE；本项目未添加自有开源许可证。
